# 🤖 GenAI Chatbot – Gemini API Integration

A conversational **AI-powered chatbot** built using **Google’s Gemini API**, designed as part of a **GenAI Hackathon** project. This minimal web interface allows users to chat with a powerful language model right in the browser.

---

## 🚀 Features

- 🔗 Integrated with **Gemini API** for natural language understanding
- 💬 Real-time chat interface using basic HTML/CSS
- 👤 Avatar-based user-bot conversation UI
- ⚡ Lightweight and fast – no backend server required (API key is client-side for now)

---

## 🧠 Tech Stack

- **HTML/CSS** – UI Design
- **JavaScript (Fetch API)** – for Gemini API integration
- **Google Gemini API** – LLM backend
- 🖼️ Images – `avatar.png`, `bot.png` for visual identity

---

## 📁 Project Structure

```
├── index.html               # Main HTML file (includes JS inline)
├── avatar.png               # User avatar image
├── bot.png                  # Bot avatar image
└── README.md
```

---


## 🛠️ How to Use

1. Open `index.html` in a browser.
2. Enter your message and click send.
3. Chatbot replies using Gemini API responses.

> ⚠️ **Note:** You need to replace the placeholder API key inside the script section of `index.html` with your own **Gemini API Key** for it to function.

```js
const apiKey = "YOUR_GEMINI_API_KEY";
```
